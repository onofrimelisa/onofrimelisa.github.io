   Period: 2017 - 2024

   Diploma scan: docs/diploma_lic.pdf

   Thesis: "Technological Innovation in Local Commerce: Development of the
   Web Platform for 'El Paseo te lo lleva'"
   Thesis document: docs/Melisa_Onofri_tesis.pdf

   Thesis summary:
     Designed and built a full-stack e-commerce web platform for a local
     solidarity marketplace ("El Paseo te lo lleva") affiliated with UNLP,
     connecting 200+ local producers with consumers. The platform replaced
     manual WhatsApp/Google Forms-based order management with a modern
     digital solution featuring role-based access (consumers, producers,
     admins), automated inventory management, business reporting dashboards,
     order lifecycle management, and a dynamic pickup-point map.
     Tech stack: Angular + TypeScript (frontend), Java + Jersey RESTful API
     with Hibernate/JPA + MySQL (backend), JWT authentication, Swagger API
     docs, Flyway DB migrations, Maven build system. Built following Agile
     methodologies (Scrumban), semantic versioning, and open-source principles.
     Deployed to production and validated with real end users across all roles.
